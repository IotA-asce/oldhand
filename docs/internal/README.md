# Internal process artifacts

Implementation plans and generation logs kept for provenance: they record
how a change was decided and what was rejected, which is exactly the kind of
reasoning this project exists to preserve.

They are **not** user documentation and are not maintained. They describe the
repository as it was on the date in each filename, so paths, command names and
version numbers in them are frequently stale — most predate the rename from
Lore to Oldhand.

Start at the [README](../../README.md) instead.
